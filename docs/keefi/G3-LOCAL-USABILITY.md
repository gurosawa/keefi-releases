# KEEFI 연결 저장과 자산 목록

이 문서는 현재 연결 저장과 자산 목록의 표시 동작을 설명한다. [금고 형식](VAULT-FORMAT.md)에 남아 있는 임시 연결 저장 설명은 이전 동작의 기록이다.

## 연결 저장

현재는 `이번 실행만 사용`이나 `이 연결을 금고에 저장`으로 임시 연결을 전환하는 흐름을 제공하지 않는다. 새 연결은 처음부터 열린 암호화 금고에 저장한다. 연결 폼은 금고가 잠겨 있으면 먼저 금고를 열도록 안내한다. 금고 생성·해제만으로 입력 중인 새 연결을 저장하지 않는다. 현재 조건은 [연결 저장 정책](G6-DIRECTION.md)을 따른다.

## 보유 자산과 검색

- 보유 여부는 원본 십진 수량으로 판단한다. 음수나 아주 작은 비영(非零) 수량도 보유로 분류하고, 수량이 없거나 유효하지 않으면 `확인 필요`로 남긴다.
- `보유 자산` 필터는 수량 0으로 확인된 행을 제외하며, 수량 확인이 필요한 행은 유지한다. 검색은 자산의 검색 문자열에 적용한다.
- 필터는 목록 행의 표시를 바꾼다. 원본 수량이나 평가 입력을 수정하지 않는다. 검색 결과가 없다는 사실과 모든 연결에 보유 자산이 없다는 판정은 다르다.
- 평가 제외 설정과 화면 필터는 별개다. 소액 숨김·가격 미확인·합계의 관계는 [평가 정책](VALUATION-POLICY.md)을 따른다.
