# KEEFI 금고 입력과 첫 자산 화면

이 문서는 현재 금고 입력과 해제 후 표시 경계를 설명한다. 파일 이름에 남은 build 56은 현재 앱 버전이나 검증 결과를 뜻하지 않는다.

## 금고 암호 입력

금고 생성·해제·암호 변경의 입력 칸은 printable ASCII를 사용한다. 지원하는 한글 음절·자모는 두벌식 영문 키로 변환하며, 기존 ASCII의 대소문자와 앞뒤 공백을 보존한다. 지원하지 않는 문자가 섞이면 해당 편집을 거부하고 일부만 잘라 받아들이지 않는다. 암호는 보기 버튼을 누르는 동안 표시한다.

이 입력 정책은 저장된 암호를 치환하거나 금고의 암호화·KDF를 바꾸는 기능이 아니다. 기존 UTF-8 암호에 대한 core 인증 호환성과 새 암호 조건은 [금고 형식](VAULT-FORMAT.md)을 따른다. UI 입력 제한과 core의 형식 호환은 구분해야 한다.

암호 확인 중에는 진행 상태를 먼저 그린다. KDF는 같은 Qt 스레드에서 동기 실행하므로, 암호 처리 내내 애니메이션이 움직인다는 보장은 아니다.

## 해제 후 자산 조회

첫 해제에서는 현재 연결의 잔고·가격 조회를 기다리는 로딩 화면을 사용한다. 디스크에 이전 평가가 있다는 이유만으로 이를 현재 값처럼 보여주지 않는다. 로딩 중에는 자산 작업 영역을 감추며, 15초가 지나면 지연을 안내한다. 이 시간은 조회 성공이나 완료 판정이 아니다.

같은 실행에서 다시 해제할 때는 직전에 검증한 연결·환경·시장·인증정보 결합·계좌 범위가 그대로이고 저장 평가가 완전한 경우에만 시각을 붙인 `마지막 확인` 화면을 사용할 수 있다. 실패·미조회·가격 부족은 완료된 정상 값으로 바꾸지 않는다. 초기 로딩이나 저장 화면의 현재 평가 진단 내보내기는 제한한다. 자세한 계산·표시 조건은 [평가 정책 §10](VALUATION-POLICY.md#10-로딩저장-화면내보내기)을 따른다.

구현 근거: [VaultDialog.cpp](../../fincept-qt/src/keefi/VaultDialog.cpp), [LocalWindow.cpp](../../fincept-qt/src/keefi/LocalWindow.cpp). 과거 화면의 고정 크기나 회전 주기를 현재 계약으로 삼지 않는다. 자동 시험·실제 OS 입력·개인 계좌 확인의 범위는 [검증 상태](VERIFICATION-STATUS.md)에서 구분한다.
