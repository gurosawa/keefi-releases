연결 순서

  1. API Management 열기

    바이낸스에 로그인해 API Management → Create API를 선택하세요. 발급 화면에서 계정 인증 관련 안내가 나오면 바이낸스에서 먼저 완료하세요.

  2. System-generated 키 선택

    키 유형은 System-generated를 선택하세요. 이 방식은 HMAC 키와 Secret을 발급합니다. 구분할 이름을 입력하고 바이낸스의 본인 인증을 마칩니다.

  3. 조회 권한과 연결할 시장 확인

    발급한 키의 Enable Reading 권한을 확인하세요. KEEFI 잔고 조회에는 주문·출금 권한을 켤 필요가 없습니다. KEEFI에서 현물 또는 USDⓈ-M 선물 중 조회할 시장을 선택합니다.

  4. KEEFI에서 키 입력

    KEEFI의 Binance 연결 창으로 돌아오세요. API Key와 Secret을 각각 넣고 저장하고 연결을 누른 뒤 선택한 시장의 조회 결과를 확인하세요.

자주 막히는 곳

키 형식 오류가 떠요

KEEFI는 System-generated HMAC 키를 지원합니다. 바이낸스 API 관리에서 발급한 키 유형을 확인하세요.

현물과 선물을 함께 보고 싶어요

KEEFI에서 다른 시장 연결을 추가하고 기존에 저장한 동일 키를 선택할 수 있습니다. 조회할 시장의 바이낸스 계정이 활성화돼 있는지도 확인하세요.
