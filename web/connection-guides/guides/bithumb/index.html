연결 순서

  1. PC 웹에서 API 관리 열기

    빗썸에 로그인한 뒤 상단 이름을 눌러 계정관리 → API 관리로 이동하세요. API 2.0 키를 발급합니다.

  2. 자산조회 권한과 허용 IP 지정

    API 활성 항목에서 자산조회만 선택하고, KEEFI를 실행할 PC에서 인터넷에 접속할 때 사용하는 공인 IP를 등록하세요. 빗썸은 허용 IP 등록을 요구합니다.

  3. 키 생성 후 두 값 복사

    약관을 확인하고 API KEY 생성을 누른 뒤 화면에 표시되는 인증을 마치세요. Secret Key는 발급 시 한 번만 표시되므로 창을 닫기 전에 복사해 안전하게 보관하세요.

  4. KEEFI에서 빗썸 연결

    KEEFI에서 계좌·연결 → 계좌 연결 → 빗썸을 선택하세요. API Key와 Secret Key를 위 표의 두 칸에 붙여넣고 금고를 연 뒤 저장하고 연결을 누르세요.

자주 막히는 곳

공인 IP를 등록했는데 접근이 거부돼요

KEEFI를 실행하는 PC에서 사용 중인 네트워크를 확인하세요. VPN 연결이나 공유기 재접속으로 공인 IP가 바뀌었다면 빗썸 API 관리에서 허용 IP를 갱신하세요.

Secret Key를 다시 확인할 수 있나요?

이미 발급 창을 닫고 Secret Key를 보관하지 않았다면 새 조회용 키를 발급하세요. KEEFI에는 같은 발급 건의 API Key와 Secret Key를 함께 입력해야 합니다.
