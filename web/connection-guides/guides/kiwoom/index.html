연결 순서

  1. 키움 REST API 사용 신청

    키움증권 계좌로 공식 포털에 로그인하세요. API 사용신청에서 서비스 이용 신청을 마칩니다.

  2. 실전 계좌와 공인 IP 등록

    계좌 App Key 관리에서 KEEFI를 실행할 PC의 공인 IP를 추가하세요. 연결할 실전 계좌를 등록하고 본인 인증을 마칩니다.

  3. App Key와 App Secret 파일 받기

    신청 현황에서 App Key와 App Secret을 각각 다운로드하세요. 키움은 각 파일을 한 번만 내려받게 하므로 두 파일을 안전한 위치에 보관하세요.

  4. KEEFI에서 두 파일 불러오기

    KEEFI 연결 창에서 키움 REST → 키 파일 2개 불러오기를 선택한 뒤 같은 계좌의 파일 두 개를 함께 선택하세요. 두 입력칸이 채워지면 저장하고 연결을 누릅니다. 차트에서 시작했다면 조회가 완료되는 즉시 보던 종목과 시간봉으로 돌아갑니다. 조회가 끝나기 전에 돌아가려면 보던 차트로 돌아가기를 누르세요.

자주 막히는 곳

키 파일을 인식하지 못해요

내려받은 원래 파일 이름과 두 파일 앞부분의 계좌번호가 같은지 확인하세요. 직접 입력하려면 각 파일의 값을 KEEFI의 App Key와 App Secret 칸에 넣으세요.

국내 분봉이나 미국 주식도 보고 싶어요

KEEFI에서 키움 연결은 국내 주식 일봉을 제공합니다. 국내 장중봉이나 미국 주식은 토스증권 연결을 선택하세요.
