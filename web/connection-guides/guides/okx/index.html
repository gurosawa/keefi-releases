연결 순서

  1. 조회할 계정에서 키 만들기

    OKX Global 웹에 로그인하고 프로필에서 API and connections → Create API key를 여세요. 키 이름을 정하고, 보려는 잔고가 있는 계정이나 하위 계정을 선택하세요.

  2. Read 권한 선택

    Permissions에서 Read만 켜세요. IP 허용 목록을 사용한다면 KEEFI를 실행할 PC의 공인 IP를 입력하세요.

  3. Passphrase 정하기

    이번 API 키에 사용할 Passphrase를 직접 정하고 보안 인증을 마치세요. 발급된 API Key, Secret Key와 함께 보관하세요. Passphrase는 생성 후 다시 확인할 수 없습니다.

  4. KEEFI에 세 값 입력

    계좌·연결 → 계좌 연결 → OKX를 여세요. 잔고는 현물, 무기한·만기 선물 포지션은 SWAP·FUTURES를 선택합니다. 표에 맞춰 세 값을 입력하고 금고를 연 뒤 저장하고 연결을 누르세요.

자주 막히는 곳

지역을 선택하는 칸이 없어요

현재 KEEFI의 신규 OKX 연결은 Global 등록 실전 계정을 사용합니다. 미국·유럽경제지역(EEA)에 별도 등록한 계정과 데모 계정은 신규 연결을 지원하지 않습니다.

Passphrase 인증에 실패해요

해당 API 키를 만들 때 정한 문자열을 대소문자까지 그대로 입력하세요. KEEFI는 Passphrase 앞뒤의 공백도 보존합니다. 잊어버렸다면 OKX에서 새 키와 Passphrase를 만들어 세 값을 함께 등록하세요.
