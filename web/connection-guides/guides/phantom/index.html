팬텀에서 주소 복사

팬텀에서 조회하려는 계정을 먼저 선택하세요. Solana 현물을 보려면 Solana, Hyperliquid 무기한 선물을 보려면 선물 거래에 사용한 계정의 Ethereum 주소를 복사합니다.

모바일 앱

홈에서 Deposit → Receive Crypto를 누르세요. 네트워크 목록에서 Solana 또는 Ethereum을 찾고 해당 행의 복사 버튼을 누릅니다.

브라우저 확장

브라우저 도구 모음에서 Phantom을 열고 홈의 Receive를 누르세요. 원하는 네트워크 행의 복사 버튼을 클릭합니다.

KEEFI에 붙여넣기

  1. 팬텀 연결 창 열기

    KEEFI의 계좌·연결 → 계좌 연결에서 지갑 그룹의 Phantom을 선택하세요.

  2. 시장 선택 후 주소 붙여넣기

    Solana 지갑(현물)을 선택하면 조회용 Solana 주소 칸이 나타납니다. 무기한 선물(Hyperliquid)을 선택하면 조회용 Ethereum 주소 칸이 나타납니다. 해당 칸에 주소를 붙여넣으면 KEEFI가 형식을 확인합니다. 다른 시장에 맞는 주소라면 Solana 현물로 전환 또는 Hyperliquid 선물로 전환을 눌러 같은 주소로 계속할 수 있습니다.

  3. 저장하고 잔고 확인

    금고가 잠겨 있으면 금고 열기를 먼저 누르세요. 저장하고 연결을 누른 뒤 조회 결과를 확인하세요. 선택한 시장의 조회가 끝났고 보유 항목이 없으면 빈 지갑으로 안내합니다. 일부만 조회되면 확인된 범위가 표시됩니다. 조회 실패가 표시되면 오류 원인을 확인한 뒤 다시 조회하세요. 두 시장을 모두 보려면 시장별로 한 번씩 등록하세요.

자주 막히는 곳

복구 문구나 개인키도 필요한가요?

KEEFI에는 팬텀의 받기 화면에서 복사한 공개 주소만 입력하세요. 복구 문구와 개인키는 지갑을 제어하는 비밀 정보입니다.

Hyperliquid 잔고가 비어 있어요

KEEFI에서 선택한 시장과 주소를 확인하세요. 팬텀의 선물 잔고는 거래한 계정의 Ethereum 주소에 연결됩니다. 이 주소는 0x 뒤에 16진수 문자 40개가 이어집니다. 팬텀에서 계정을 여러 개 사용한다면 같은 계정의 주소인지 확인하세요. 팬텀의 선물 잔고 안내 (새 탭)
