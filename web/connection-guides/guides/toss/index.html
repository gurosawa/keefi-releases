연결 순서

  1. 토스증권에서 Open API 열기

    이 페이지 상단의 토스증권에서 키 발급을 누르고 토스증권 계좌가 있는 계정으로 로그인하세요.

  2. 키 발급과 허용 IP 확인

    Client ID와 Client Secret을 발급받으세요. 토스증권 웹의 설정 → Open API → 허용 IP 관리에서 KEEFI를 실행할 PC의 공인 IP를 확인하고 등록하세요.

  3. KEEFI에서 토스증권 연결

    열어 둔 KEEFI 연결 창으로 돌아가 두 값을 같은 이름의 칸에 붙여넣으세요. 금고를 열고 저장하고 연결을 누릅니다. 차트에서 시작했다면 조회가 완료되는 즉시 보던 종목과 시간봉으로 돌아갑니다. 조회가 끝나기 전에 돌아가려면 보던 차트로 돌아가기를 누르세요.

자주 막히는 곳

IP가 허용되지 않았다고 떠요

PC에서 쓰는 인터넷이나 VPN을 바꿨다면 토스증권의 허용 IP를 다시 확인하세요.

이미 등록했는데 차트가 비어 있어요

KEEFI 금고가 열려 있는지 먼저 확인하세요. 인증 만료 안내가 보인다면 계좌·연결에서 토스증권을 다시 연결하세요.
