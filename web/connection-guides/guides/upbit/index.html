연결 순서

  1. PC 웹에서 Open API 관리 열기

    고객 확인과 2채널 인증을 마친 업비트 계정으로 PC 웹에 로그인하세요. 마이페이지 → Open API 관리를 엽니다.

  2. 자산조회 권한과 허용 IP 설정

    계좌 잔고 확인에 필요한 자산조회 권한을 선택하고, KEEFI를 실행할 PC의 공인 IP를 등록하세요. 조회용 키에는 주문·출금 권한이 필요하지 않습니다.

  3. 발급한 두 값 확인

    Open API Key 발급을 요청하고 2채널 인증을 마치세요. Secret Key는 최초 발급 때만 볼 수 있으니 발급 화면이 열려 있을 때 KEEFI에 입력하세요.

  4. KEEFI에서 업비트 연결

    KEEFI의 Upbit 연결 창으로 돌아가 Access Key와 Secret을 각각 붙여넣으세요. 금고를 열고 저장하고 연결을 누른 뒤 자산 조회 결과를 확인하세요.

자주 막히는 곳

휴대폰에서 발급 메뉴를 찾을 수 없어요

업비트 API 키 발급은 PC 웹에서 진행합니다. 휴대폰은 2채널 인증 단계에서 사용할 수 있습니다.

자산조회 권한 또는 IP 오류가 떠요

업비트 Open API 관리에서 발급한 키의 자산조회 권한과 현재 PC의 허용 공인 IP를 확인하세요.
